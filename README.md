# 🍽️ Recipe Sharing Application (.NET)

## 📌 Introduction

This project is a web-based application designed for storing and sharing cooking recipes. It allows users to explore, interact, and manage recipe content through an intuitive interface. The system aims to provide a simple and engaging platform for users to discover and share culinary ideas.

---

## 🚀 Features

* 🔍 Browse and view detailed recipes
* ❤️ Like, comment, and share recipes
* 📌 Save favorite recipes to personal collection
* 👤 User interaction and engagement system
* 🛠️ Admin/content management capabilities
